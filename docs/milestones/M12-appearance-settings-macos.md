# M12 — Appearance, settings & macOS integration

**Goal:** Add themes, tag management, the remaining General settings, updates and OS integration.
**Ref:** Guide › Ch. 11 Appearance settings and macOS integration.

## Items

### M12.01 Theme engine
- [ ] Built-in themes: Default (follows the system appearance), Dark, Light, ForkLift, Bluerange, Dracula, Commander, Sand, Polar Night.
- [ ] Theme definitions are data files, so custom themes can be added later *(custom themes are vendor-documented)*.

### M12.02 Tag management
- [ ] Settings › Tags: default Gray, Green, Purple, Blue, Yellow, Red, Orange, with Add and Remove.
- [ ] The sidebar shows these tags. Clicking a tag lists the files that have it.

### M12.03 Drag confirmation
- [ ] Settings › General › Ask for confirmation for drag operations (default off) shows a copy/move confirmation after a drop.

### M12.04 Startup settings
- [ ] Starting Directory (default Home) and Restore windows and tabs are connected to M02.11.

### M12.05 About & updates
- [ ] About window shows the version and build.
- [ ] Check for Updates, an automatic-check toggle (default off) and Check for Updates Now.

### M12.06 Services & sharing
- [ ] ForkLift › Services exposes the system Services menu for the current selection.
- [ ] Share menu/integration *(vendor-documented)*.

### M12.07 System text features
- [ ] Edit menu includes the standard Dictation, Emoji & Symbols and AutoFill entries (provided by the OS).

### M12.08 Permissions & notifications onboarding
- [ ] On first run, a guide explains Full Disk Access and asks for notification permission.
- [ ] When an access error happens, the app explains which permission is missing and links to System Settings.

### M12.09 Localization
- [ ] All UI strings are externalized. Ships in English, ready for more languages *(more languages are vendor-documented)*.
